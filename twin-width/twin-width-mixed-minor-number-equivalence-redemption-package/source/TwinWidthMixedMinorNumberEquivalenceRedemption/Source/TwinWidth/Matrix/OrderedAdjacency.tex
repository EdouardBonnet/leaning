\(\mathrm{VertexOrder}(V,n)\) is an equivalence \(\mathrm{Fin}\,n\simeq V\),
used as an ordering of the finite vertex type \(V\).

For a graph \(G\) and vertex order \(\sigma\), the matrix
\(\mathrm{orderedAdjacency}(G,\sigma)\) is the Boolean \(n\times n\) matrix
whose \((i,j)\)-entry is true exactly when \(G\) has an edge between
\(\sigma(i)\) and \(\sigma(j)\).

\(\mathrm{orderedAdjacencyMixedNumber}(G,\sigma)\) is the matrix mixed number of
this ordered adjacency matrix.
