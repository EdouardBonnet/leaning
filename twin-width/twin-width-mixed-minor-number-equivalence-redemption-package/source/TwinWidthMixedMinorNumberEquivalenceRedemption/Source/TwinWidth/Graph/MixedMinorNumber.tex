\(\mathrm{mixedMinorNumber}(G)\) is the least natural number realized as the
mixed number of an ordered adjacency matrix of \(G\), ranging over vertex orders
\(\sigma:\mathrm{Fin}\,|V|\simeq V\).  Thus it minimizes
\(\mathrm{orderedAdjacencyMixedNumber}(G,\sigma)\) over all linear orders of the
finite vertex set.
