This submission gives a full Lean proof that twin-width and mixed minor number
are functionally equivalent for finite simple graphs with decidable adjacency.
The twin-width definition in the submitted theorem is imported from the
Redemption 2 submission on the
exponential separation between twin-width and treewidth.  The statement expands
functional equivalence directly into the two bounding-function existentials, and
the package includes the source mixed-minor definition chain: ordered divisions,
mixed matrix cells, mixed minors, matrix mixed number, ordered adjacency
matrices, and graph mixed minor number.
The proof reuses the self-contained source theorem chain through Marcus--Tardos,
matrix Theorem 10, Theorem 14, and the graph twin-decomposition bridge, together
with a proof that the source twin-width definition agrees with the imported
Redemption 2 definition.
