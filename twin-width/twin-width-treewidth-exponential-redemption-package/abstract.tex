This submission proves the Bonnet--Depres separation in the form: for every natural number $k$, there is a finite simple graph $G$ with $\operatorname{tw}(G)\le 2k+4$ and $2^k<\operatorname{tww}(G)$. The submitted statement includes transparent definitions of treewidth, twin-width, tree decompositions, trigraph states, contraction steps, and bounded-width contraction sequences.
